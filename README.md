# Employee Management System

A full-stack web application for managing employee records, built with the **MERN** stack.

## Features

- Add, view, edit, and delete employee details
- Manage employee roles, departments, and contact information
- Secure user authentication
- Responsive user interface

## Tech Stack

- **MongoDB** — database
- **Express.js** — backend API
- **React.js** — frontend
- **Node.js** — server runtime

## Getting Started

1. Clone this repository.
2. Install dependencies in both the client and server folders:

   ```bash
   npm install
   ```

3. Add your MongoDB connection string and environment variables.
4. Start the backend and frontend:

   ```bash
   npm run dev
   ```
